时隔多年之后，捡起了互联网古早的“个人网站”开始维护，是一个奇特的体验。

不想称呼为Blog，是仅仅准备放一些工作及相关的想法上来。

## 技术栈

| 环节 | 选择               | 原因                                         |
| ---- | ------------------ | -------------------------------------------- |
| 框架 | Astro              | 默认零 JS，内容型站点加载极快                |
| 主题 | AstroPaper         | 排版克制，自带暗色模式和全文搜索             |
| 样式 | Tailwind CSS       | 改配色和间距不用翻 CSS 文件                  |
| 搜索 | PageFind           | 构建时生成静态索引，不需要任何后端           |
| 托管 | Cloudflare Workers | 静态资源直接分发，不经过服务端脚本，不耗额度 |

---

本站使用 [AstroPaper](https://github.com/satnaing/astro-paper) 主题。
