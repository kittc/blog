这是这个博客的第一篇文章。与其写一篇「Hello World」，不如把建站的技术选型讲清楚，顺便当作给自己留的一份备忘。

## 技术栈

| 环节 | 选择             | 原因                                     |
| ---- | ---------------- | ---------------------------------------- |
| 框架 | Astro            | 默认零 JS，内容型站点加载极快            |
| 主题 | AstroPaper       | 排版克制，自带暗色模式和全文搜索         |
| 样式 | Tailwind CSS     | 改配色和间距不用翻 CSS 文件              |
| 搜索 | PageFind         | 构建时生成静态索引，不需要任何后端       |
| 托管 | Cloudflare Pages | 免费额度宽松，国内访问比同类海外平台稳定 |

## 一个纯静态站的好处

整站在构建时就把 HTML 生成好了，访问时不需要跑任何服务端代码。这意味着：

- 没有数据库要维护，也就没有宕机风险
- 没有服务器费用，流量涨了也不用扩容
- 文章本质就是仓库里的 Markdown 文件，天然有版本历史

写文章的工作流因此变得很短：新建一个 `.md` 文件，提交，推送到 GitHub，Cloudflare Pages 自动构建上线。整个过程不需要打开任何后台管理界面。

## 接下来

打算写这几类内容：

1. 工程实践中踩过的坑，以及最后为什么那样解决
2. 读过的书和技术文章里值得记下来的部分
3. 一些没有结论、只是想清楚一点的想法

写作对我而言更像是把模糊的直觉整理成句子的过程。如果某篇文章恰好对你有用，那算是额外的收获。
